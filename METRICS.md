# Product metrics

`npm run metrics` reports non-QA unique users, prefecture selectors, successful and no-result search events, use-filter users, comparison users, copiers, official-source openers, and returning comparison users. Seven-day searcher and copier counts show early movement.

A successful search is emitted only when a local query of two or more normalized characters returns at least one point. No query, prefecture, point identifier, address, station, coordinates, or use value enters telemetry.
